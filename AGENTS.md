# Agent instructions

This repository contains one skill: `skills/nz-job-application/`.

When the user asks to set up a job profile, apply for a job (gives a job link
or pastes an advert), update their profile, or record an application outcome,
read `skills/nz-job-application/SKILL.md` and follow it exactly, including
every checkpoint where you must stop and wait for the user.

The user's personal data lives in `my-job-search/`. Never copy anything from
it into any other folder of this repository.
